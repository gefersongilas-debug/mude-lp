# Museu Flamengo + Tour da Gávea

Landing page em Next.js para apresentar a experiência combinada do Museu Flamengo e do Tour da Gávea.

## Desenvolvimento

```bash
npm install
npm run dev
```

A aplicação ficará disponível em `http://localhost:3000`.

## Produção

```bash
npm run build
npm start
```

## Stack

- Next.js 16
- React 19
- TypeScript
- GSAP e ScrollTrigger
